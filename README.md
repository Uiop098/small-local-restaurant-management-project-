# 🍲 Mess & Local Restaurant Management System

A lightweight, serverless, browser-based Meal Attendance Ledger and Billing Management Dashboard designed for student messes, hostels, cafeterias, and local restaurants.

## 📊 Overview

The Mess Management System replaces paper notebooks and manual spreadsheets with an intuitive digital ledger for tracking daily meal consumption, calculating billing charges, and generating financial summaries.

---

## 🌟 Key Features

- **📋 Meal Attendance Tracking:** Record daily attendance across **Breakfast**, **Lunch**, **Snacks**, and **Dinner**.
- **👥 Guest Meal Billing:** Automatically calculate charges for regular members versus guest meals.
- **💰 Configurable Pricing Matrix:** Customize rates per meal type and member tier.
- **📥 Data Portability:**
  - **Export CSV/Excel:** Download complete meal logs with a single click.
  - **Import CSV:** Restore or merge previous attendance records.
- **📈 Analytics & Totals:** Live calculation of total meals served, total revenue collected, and active member balances.
- **🔒 Local Persistence:** All data is safely stored in browser `localStorage`—no backend server or database setup required.

---

## 🚀 How to Use

1. Clone or download the repository:
   ```bash
   git clone https://github.com/Uiop098/small-local-restaurant-management-project-.git
   cd small-local-restaurant-management-project-
   ```
2. Open `index.html` in your web browser.
3. Enter member details, select the meal type, and click **Record Meal**!

## 🛠️ Technologies Used

- **JavaScript (ES6+):** Client-side ledger operations, CSV parser/exporter, and LocalStorage data engine.
